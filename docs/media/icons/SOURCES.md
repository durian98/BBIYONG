# 구성도 로고 출처

확인일: 2026-10-02

`architecture.svg`는 로고 경로, 글자와 도형을 포함한 벡터 파일입니다. 외부 이미지 파일이나 래스터 이미지를 포함하지 않습니다. `architecture.png`는 README 미리보기용 내보내기입니다.

## Jenkins

Jenkins 캐릭터는 [Jenkins project](https://www.jenkins.io/)의 공식 SVG 원본을 사용했습니다. 원본 디자인은 Frontside가 제작했습니다.

- [공식 Artwork 안내](https://www.jenkins.io/artwork/)
- [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

## 기술 아이콘

React, Spring, MySQL, Nginx, Docker, GitLab, NVIDIA, Mattermost 아이콘은 [Simple Icons](https://github.com/simple-icons/simple-icons)에서 가져왔습니다. Simple Icons 배포 라이선스는 [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)입니다. 각 브랜드의 이름과 로고 권리는 해당 권리자에게 있습니다.

AWS EC2의 구름, 영상 서버와 저장소 기호는 구성도를 위해 직접 작성한 SVG 도형입니다.
